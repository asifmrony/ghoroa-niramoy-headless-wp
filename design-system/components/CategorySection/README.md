A homepage block giving a three-article glimpse of one category.

**Markup:** `section.gn-section` > `.gn-section__head` (`h2.gn-section__title` category name + `a.gn-section__more` "সব দেখুন →", over a 2px `primary` rule) > `.gn-catblock`: one lead `article.gn-catblock__lead` (16:10 image, tag, title, excerpt, meta) and a `ul.gn-catblock__side` with two compact items (title, reading time, 1:1 thumb), separated by `line` hairlines.

- One block per category: ঘরোয়া টোটকা, ভেষজ উদ্ভিদ, রান্নাঘরের মসলা, ছাদবাগান.
- Wrap two blocks in `.gn-catpair` to set them side by side (each stacks lead over list); use this after the video band to vary the rhythm.
