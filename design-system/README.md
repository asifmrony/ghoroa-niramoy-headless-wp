# GhoroaNiramoy design system (v1)

Design system for **ঘরোয়া নিরাময় / GhoroaNiramoy**, a Bengali natural-remedies and rooftop-gardening blog.

- `previews/index.html`: open in a browser to see every component and the Home and Article pages (light and dark).
- `CLAUDE.md`: instructions for Claude Code when building the site from this package.
- `docs/brand-book.md`: brand and usage rules.
- `docs/architecture.md`: Astro + WordPress/WooCommerce platform plan and setup checklist.
- `tokens/`, `css/`, `fonts/`, `assets/`, `scripts/`: the files you import into the site.

To use with Claude Code: copy this folder into your project (e.g. `design-system/`) and tell Claude to read `design-system/CLAUDE.md` first.
